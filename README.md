# Skyfall-GS project page

Source for https://skyfall-gs.jayinnn.dev/, the project page of *Skyfall-GS: Synthesizing Immersive 3D Urban Scenes from Satellite Imagery* (ECCV 2026).

- Paper: https://arxiv.org/abs/2510.15869
- Code: https://github.com/jayin92/Skyfall-GS

The page is plain HTML, CSS and JavaScript with no build step. To preview it locally:

```bash
python3 -m http.server 8000
```

then open http://localhost:8000.

Earlier versions of this page were built on the [Nerfies](https://nerfies.github.io) project page template.
